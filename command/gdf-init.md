# gdf-init - 项目初始化指令
version: 1.0.0

## 触发条件
用户输入 `gdf-init`

## 执行流程

### 第0步：检查是否已初始化

检查 `.gdf/standards.md` 是否存在：

- **已存在**：提示用户项目已完成初始化，是否需要重新初始化
  ```
  当前项目已完成初始化。

  上次初始化时间：[日期]
  是否重新初始化？
  - 输入 `是` - 重新执行初始化（会覆盖现有规范）
  - 输入 `否` - 保持现有配置
  - 输入 `查看` - 查看当前规范文档
  ```

- **不存在**：继续执行初始化

### 第1步：选择初始化方式

输出：

```
初始化项目需要分析代码样本，请选择初始化方式：

1. 【推荐】读取现有项目 - 分析当前项目代码，自动识别技术栈
2. 读取子系统/模块 - 分析指定的子系统或模块代码
3. 用户上传 - 你手动粘贴 2-5 个代码文件

请输入选项编号（1/2/3），或直接描述你的需求：
```

#### 方式1：读取现有项目

```
请稍候，我正在扫描当前项目的代码结构...

分析完成！找到以下技术栈：
- 后端：[技术栈]
- 前端：[技术栈]

请确认是否正确？
```

#### 方式2：读取子系统/模块

```
请告诉我你要初始化的子系统或模块名称。

例如：
- "订单模块"
- "用户中心"
- "后台管理系统"

输入名称后，我会分析该模块的代码结构。
```

#### 方式3：用户上传

```
请提供代码样本（2-5个文件）。

要求：
- 选择功能完整的文件（包含增删改查更好）
- 覆盖前后端/不同模块类型

请逐个粘贴文件内容。
```

### 第2步：技术栈识别

收到代码后，分析并输出：

```
## 技术栈识别结果

### 后端技术
- 语言：[C#/Java/Python/Go/Node.js/PHP]
- 框架：[.NET/Spring Boot/Express/Laravel]
- API模式：[RESTful/Handler/Controller]
- 数据库访问：[ORM/原生SQL/Query Builder]

### 前端技术
- 框架：[React/Vue/Angular/jQuery/原生JS]
- UI库：[Element UI/Ant Design/EasyUI/Bootstrap]
- HTTP请求：[axios/fetch/jquery.ajax]

### 数据格式
- 请求格式：[JSON/FormData/XML]
- 响应格式：[统一结构/非统一]
- 分页参数：[page/pageSize/page/rows/offset/limit]
- 日期格式：[ISO/时间戳/自定义]

请确认以上识别是否正确？

- 输入 `确认` - 识别正确，生成规范
- 输入 `修改 [项目] = [值]` - 修改指定项
```

### 第3步：生成规范文档

用户确认后，参考模板 `../templates/coding-standards.md` 生成项目编码规范文档，**保存到 `.gdf/standards.md`**。

### 第4步：生成代码模板

基于规范生成模板文件到 `.gdf/templates/`：
- 后端处理程序模板
- 前端列表页模板
- 公共函数库（如适用）

### 第5步：完成提示

```
✅ 初始化完成！

项目信息：
- 技术栈：[技术栈]
- 规范文档：.gdf/standards.md
- 代码模板：.gdf/templates/

后续使用：
- gdf-need - 录入需求
- gdf-status - 查看状态
```

---

## 注意事项

1. 首次初始化前必须选择初始化方式
2. 重复执行 gdf-init 必须先确认，否则只查看现有配置
3. 代码样本选择要有代表性，覆盖不同模块类型
4. 识别的技术栈需要用户确认后才能生成规范
5. 规范文档生成后需要用户确认

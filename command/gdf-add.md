# gdf-add - 添加功能指令

## 触发条件
用户输入 `gdf-add`

## 执行时机
需要为已完成的模块增加新功能时

## 前置条件
项目已完成初始化（`gdf-init` 已执行）

## 执行流程

### 第1步：选择模块

输出：

```
请选择要添加功能的模块：

1. [模块A] - 状态：已完成
2. [模块B] - 状态：已完成
3. [模块C] - 状态：进行中
...

或者输入：
- `新建` - 创建新模块（使用 gdf-need）
- `列表` - 显示所有模块列表
```

等待用户选择，或输入模块名称搜索。

### 第2步：确认目标模块

用户选择后，显示模块信息：

```
已选择模块：[模块名称]

当前功能：
- [功能1]
- [功能2]
- [功能3]

请描述要添加的新功能：
```

### 第3步：快速QA

新功能确认后，进行快速澄清（2-3个关键问题）：

```
好的，要添加：[新功能名称]

快速确认几个问题：
```

**根据功能类型动态提问**：

| 功能类型 | 问题示例 |
|----------|----------|
| 导出功能 | 导出范围（当前页/全部）？导出格式（Excel/CSV/PDF）？ |
| 导入功能 | 导入文件格式？是否需要模板？重复数据如何处理？ |
| 批量操作 | 批量选择上限？操作类型？ |
| 通知功能 | 触发时机？通知方式（邮件/短信/站内）？ |
| 打印功能 | 打印模板？纸张大小？是否需要预览？ |

### 第4步：生成增量需求

QA完成后，参考模板 `../templates/incremental-requirement.md` 生成增量需求文档，**保存到 `.gdf/increments/{模块名}-{功能名}.md`**。

### 第5步：等待确认

```
---

请确认增量需求：
- 输入 `确认` - 开始生成增量代码
- 输入 `修改 [内容]` - 修改需求
- 输入 `取消` - 取消操作
```

### 第6步：生成增量代码

确认后，分析现有代码结构，生成增量代码（使用代码块格式展示）。

### 第7步：输出总结

```
---

✅ 增量代码生成完成！

变更摘要：
- 修改文件：N 个
- 新增文件：N 个
- 代码行数：+N 行

请检查代码，确认是否需要调整：
- 输入 `调整 [内容]` - 调整代码
- 输入 `确认` - 锁定代码
```

### 第8步：锁定完成

用户确认后：

```
✅ 功能已添加！

模块：[模块名称] - 已更新
新功能：[功能名称] - 已完成

下一步：
- 输入 `gdf-status` 查看项目状态
- 输入 `gdf-add` 继续添加其他功能
```

## 注意事项

1. **最小改动原则**：只添加必要代码，不修改现有功能
2. **兼容性考虑**：新增功能不影响现有功能
3. **代码复用**：优先使用已有的公共方法/组件
4. **影响评估**：提前说明对现有模块的影响

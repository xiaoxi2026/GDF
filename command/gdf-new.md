# gdf-new - 任务执行指令
version: 1.0.0

## 触发条件
用户输入 `gdf-new`

## 前置条件
已确认的任务清单（由 `gdf-split` 生成）

## 执行流程

### 第1步：加载任务清单

检查 `.gdf/tasks/` 目录下的任务文件：

- 存在已锁定任务：加载任务清单
- 不存在：提示用户先执行 `gdf-split`

### 第2步：展示待办任务

输出当前任务列表，标记可执行的任务：

```
📋 当前任务清单：[模块名]

| 任务ID | 描述 | 状态 | 预估时间 |
|--------|------|------|----------|
| T01 | 数据库设计 | ✅完成 | 0.5h |
| T02 | 后端框架搭建 | 🔄进行中 | 1h |
| T03 | 列表API开发 | ⏳待处理 | 1h |
| T04 | 新增API开发 | ⏳待处理 | 1h |

请选择要执行的任务：
- 输入 `T03` - 执行指定任务
- 输入 `下一个` - 自动选择下一个待处理任务
- 输入 `状态` - 查看完整状态
```

### 第3步：执行单个任务

根据任务类型执行相应操作：

#### 3.1 数据库设计任务

1. 参考 `.gdf/templates/` 中的数据库模板
2. 生成建表SQL或ER图
3. 输出SQL脚本供用户确认

#### 3.2 后端API任务

1. 分析现有代码模式（参考 `.gdf/standards.md`）
2. 生成API代码（Controller/Service/Model）
3. 等待用户确认

#### 3.3 前端页面任务

1. 分析现有前端代码模式
2. 生成页面代码（列表/表单/详情）
3. 等待用户确认

#### 3.4 测试任务

1. 编写测试用例
2. 执行测试并报告结果

### 第4步：代码产出

每次产出代码后：

```
---

请确认生成的代码：
- 输入 `确认` - 代码正确，标记任务完成
- 输入 `修改 [内容]` - 修改部分代码
- 输入 `重做` - 重新生成
- 输入 `跳过` - 暂时跳过此任务
```

### 第5步：任务完成

用户确认后：

1. 将生成的代码保存到项目目录
2. 更新任务状态为"已完成"
3. 输出完成报告

```
✅ 任务 T03 完成！

产出文件：
- src/api/user.js
- src/views/user/List.vue
- src/views/user/Form.vue

下一步：
- 输入 `gdf-new` 继续下一个任务
- 输入 `gdf-status` 查看整体进度
```

### 第6步：循环执行

重复步骤2-5，直到所有任务完成。

当全部任务完成时：

```
🎉 所有任务已完成！

模块：[模块名]
完成任务数：N个
总耗时：X小时

后续操作：
- 输入 `gdf-add` - 添加新功能
- 输入 `gdf-refactor` - 代码优化
- 输入 `gdf-status` - 查看项目状态
```

---

## 注意事项

1. **每次只执行一个任务**：避免一次生成过多代码
2. **严格按照规范**：参考 `.gdf/standards.md` 生成代码
3. **等待确认**：生成代码后必须等待用户确认才能标记完成
4. **记录产出**：所有生成的代码必须保存到项目目录
5. **异常处理**：执行出错时，详细说明错误原因和解决建议
